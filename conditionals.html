Conditionals (الجمل الشرطية)

Conditional sentences are essential for BAC exams. They express conditions and their results.

Zero Conditional (حقيقة عامة)

Form: If + Present Simple, Present Simple

Use: General truths, scientific facts, things that are always true

If you heat water to 100°C, it boils.
If it rains, the grass gets wet.

First Conditional (محتمل في المستقبل)

Form: If + Present Simple, will + V1 (infinitive)

Use: Real and possible future situations

If it rains tomorrow, I will stay home.
If you study hard, you will pass the BAC exam.

Variations: can, may, might, should, must can replace "will"

Second Conditional (غير محتمل / تخيلي)

Form: If + Past Simple, would + V1

Use: Unreal or imaginary present/future situations, hypothetical scenarios

If I had a million dollars, I would travel the world.
If I were you, I would study more. (Note: "were" for all subjects)

Third Conditional (مستحيل / ندم على الماضي)

Form: If + Past Perfect, would have + V3

Use: Unreal past situations — expressing regret or imagining different outcomes

If I had studied harder, I would have passed the exam.
If we had left earlier, we would have caught the train.

Mixed Conditional

Form: If + Past Perfect, would + V1

Use: Past condition with a present result

If I had taken that job, I would be rich now.
If she had studied medicine, she would be a doctor now.

"Unless" = "If not"

Unless you study, you will fail. (= If you do not study...)
I won't go unless he invites me. (= I will go only if he invites me.)

⚠️ Common BAC Mistakes

  • Never use "will" or "would" in the IF clause!
  • Remember the comma when "if" starts the sentence.
  • In Second Conditional, use "were" for all subjects with "to be".
  • Third Conditional expresses regret — use it in writing for emotional effect.
